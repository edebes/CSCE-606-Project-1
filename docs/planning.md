What app the team will build
  This is a typing app that allows users to maintain a wordbank of words they want to get better at typing and practice with all of those words. It will track the user’s speed and accuracy of their typing so they can reflect on how they have improved.
Which features are essential and which are optional
Essential:
  Create sentences with wordbank words for user to practice typing
  Timer to record user’s speed of typing
  CRUD wordbank
  Basic accuracy (correct characters 1st time / total # of characters)
Optional:
  Leaderboard to record fastest times of user’s attempts
  Complicated accuracy for typing the characters (proximity, time-based, offset)
  Two “player” mode
  Live timer
How the team will collaborate on work (individual vs. pair programming)
  So far most work has been individual since there's two "halves" to the project (word bank vs typing speed) but as we get to more complicated features, we will do more pair programming.
What “done” means for the project and for individual features/stories
  Done means passing some kind of test cases, whether programmed or manually done by users, this applies for the project and for individual features/stories.
